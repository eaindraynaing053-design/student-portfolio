# Student Portfolio

A simple and responsive student portfolio website built using HTML and CSS.

## About

This project was created to showcase my personal profile, education, skills, and projects. It also demonstrates my understanding of basic front-end web development.

## Features

- About Me
- Skills
- Education
- Projects
- Contact Information
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Project Structure
student-portfolio/
├── index.html
├── style.css
└── README.md

## Getting Started

Clone the repository:
git clone https://github.com/eaindraynaing053-design/student-portfolio.git

Open the project folder and run index.html in your web browser.

## Purpose

This project was developed as part of my learning journey to practice HTML, CSS, Git, and GitHub while creating a professional portfolio website.
